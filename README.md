# Shelfwise

Track what you read, rate and review books, curate public collections — and ask an AI reading advisor what to read next, grounded in a real catalog.

> **Status:** architecture & planning. No code yet — see the [roadmap](docs/roadmap.md).
> Screenshots, live demo link and a chat GIF will be added in roadmap step 19.

## Stack

Next.js (App Router) · React · TypeScript · Tailwind · TanStack Query · NestJS · Prisma · PostgreSQL · Zod · Vercel AI SDK + Gemini Flash · Jest · GitHub Actions · Vercel · Render · Neon
